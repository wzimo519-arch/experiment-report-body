# course_experiment

在保留用户原始 Word 文档和排版的前提下，只完成实验正文部分。

## 使用前必须确认

开始修改前，必须取得以下信息：

1. 原始实验报告文件。
2. 代码必须写入的目录。
3. 编写代码使用的编辑器名称，例如 VS Code 或 IntelliJ IDEA。

缺少任何一项时停止并询问，不得猜测报告、目录或编辑器。

编辑器用于确认代码落点和打开代码文件。实际运行或编译命令由 agent 根据报告语言和本机环境检测；只有需要安装环境或依赖时，才按当前权限流程处理。

## 修改边界

只修改用户明确指定的实验正文，通常包括实验步骤、实验结果、实验分析和对应截图；正文上方“实验报告文件信息”区域的空白处仅可用于放置用户要求的截图。

不得修改或替换：

- 封面和个人信息。
- 预习、预实验或课前内容。
- 成绩、签名、评语、批注等评分信息。
- 与当前实验无关的章节或其他实验内容。

不得创建第二份 Word 文档。直接修改原始文件并原位保存。

## 内容落点

1. 优先查找表格单元格、形状框、文本框、内容控件等专门填写位置。存在这类位置时，内容必须写在对应的框或单元格内，不得另起段落绕过。
2. 代码截图和步骤、过程、运行等截图，在没有专用填写位置时，优先放入实验正文上方“实验报告文件信息”区域的空白处。
3. 使用该空白处时不得覆盖、挪动或改写已有报告信息；空白不足或放置后影响阅读时，放到对应正文步骤附近。

## 闭环流程

1. 先只读检查报告，定位准确标题、专用填写位、文件信息区空白处、字体、字号、行距和页面布局。
2. 根据实验内容实现满足要求的最小代码，不增加无关功能或依赖。
3. 只在用户指定目录写入代码，并使用用户指定编辑器打开；运行真实测试或示例输入，保留实际输出，不得伪造截图或结果。
4. 按“专用填写位优先，文件信息区空白处次之，对应正文附近兜底”的顺序放置内容。只插入报告要求的内容：代码、输出、截图、表格和分析；保持周边格式，每张图片独占一个段落，图题与图片保持同页。
5. 原位保存原始文件。逐页渲染所有受影响页面，检查裁切、重叠、孤立图题、分页错误或截图不可读，修复后重新渲染。
6. 汇报实际结果、代码路径，以及超出本次范围但仍然存在的文档级问题。

## 阶段与工具命令

使用当前环境中可用的文档与代码工具。报告编辑优先调用 `documents` skill 的现有能力，不重新实现 Office 解析器。

| 阶段 | 常用命令 | 检查点 |
|---|---|---|
| Plan | 打开原文件、读取正文与表格、渲染受影响页面 | 找到唯一题名、填写位和样式 |
| Do | 读写指定代码目录，执行真实输入；截图；写入专用位置或正文 | 代码、输出和截图真实，不覆盖无关区域 |
| Check | 原位保存，逐页渲染受影响页面 | 文件路径和格式不变，所有受影响页面可读 |
| Act | 修正内容或版式后重新渲染 | 只修复当前填写导致的问题 |
| Close | 保留并汇报原报告 | 不创建重复文档，不关闭用户文档 |

出现版式问题时只修复当前填写造成的内容；不要为了修正局部问题重排整份报告。
