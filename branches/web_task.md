# web_task

把用户给出的 URL 和题目清单转换成可验证的完成结果。页面是任务内容和进度的唯一事实来源。

## 输入

必需：

1. 页面 URL。
2. 要完成的题目名称、题号范围，或“当前页面上的指定题目”。

若页面不能唯一确定题目范围，先询问；不要顺手完成整页内容。

用户要求“完成并提交”时，可在指定题目范围内操作答案、编辑器和评测按钮。登录、验证码、权限弹窗、敏感信息或不可逆操作仍按当前环境的确认策略处理。不要代填密码，也不要把凭据写入文件。

## 闭环

1. 打开或绑定页面，核对域名、标题和当前账号；需要登录时交给用户。
2. 先读课程或练习总览，再进入题型页。存在多个题型时分别核对题数、分值和完成条件，将用户指定项映射为唯一任务；记录 `待处理`、`处理中`、`已提交`、`已验证`、`阻塞`。
3. 每次只打开一个目标题目，读取任务描述、选项、输入输出和编辑器内容。
4. 选择题按题目容器和选项文本定位，不用页面绝对序号。选择后读回选中状态；若平台在判分后提供“查看答案”或解析，用它核对错误项后再修正。
5. 代码题先区分普通源码编辑器和“单处/多处填空”编辑器。普通编辑器先读取模板，再做最小修改；填空编辑器只替换指定空位，并按平台要求确认后再提交。
6. 页面有多个编辑器时，按可见区域和当前题目绑定编辑器，不选隐藏的全局编辑器。覆盖内容时聚焦、全选、粘贴，再从页面读回源码确认。
7. 有自测时先自测，再正式评测。评测可能异步执行；看到“正在评阅”“服务器正在运行”等中间状态时继续轮询，直到出现通过、失败或超时结论。
8. 单题通过后进入下一题。整组完成后读取成绩单，再回到课程总览核对总进度。
9. 新标签页出现后重新列出标签页，按标题和 URL 唯一匹配；清理本次创建且已完成的任务页。

## 题型处理

| 题型 | 作答方式 | 完成证据 |
|---|---|---|
| 单选/多选 | 在对应题目内选择，必要时保存 | 选项选中状态、保存成功提示 |
| 自动判分选择题 | 保存后由平台立即判分，通常没有统一“交卷” | 成绩单分值；已判分题的“查看答案”或解析 |
| 普通代码题 | 覆盖完整源码，读回后提交 | 单题百分比、全部测试通过、单题得分 |
| 填空代码题 | 点击指定空位，只填写缺失代码并确认 | 填充内容已进入源码、单题得分 |

不要把一个平台的操作当成所有平台都有同样按钮。只有页面真实存在对应按钮时才称之为“交卷”“评测”或“提交”。

## 编辑器规则

- 普通代码页优先定位当前题目详情旁的可见编辑器。页面可能同时保留隐藏的全局编辑器，第一个 DOM 元素不一定是目标。
- ACE、CodeMirror 等代码编辑器通常有隐藏输入框。点击可见代码区后按 `Control+A`，粘贴内容，再读取渲染后的代码行确认。
- 从“答案解析”返回“提交代码”时，编辑器可能折叠或重新挂载。重新获取页面状态和编辑器标识后再填写。
- 填空模式一般要求点击“点击在此输入一行或多行代码”等占位文本。粘贴后检查空位内是否只包含缺失代码，点击“确认”，再提交完整程序。
- 已有前置输入语句时，不要在填空区再次粘贴整份模板，否则会重复读取输入或覆盖平台约束。

## 修正规则

- 先看页面给出的预期输出、实际输出、测试用例和解析，再改代码。
- 输出逐字符匹配：重点检查中文标点、尾随句号、空格、换行和大小写。
- 选择题首次得分不完整时，打开判分后的答案视图核对；不要靠反复猜选项。
- 异步评阅只等待最终状态。中间百分比或“正在评阅”不能当作通过或失败。

## 失败处理

- 有预期/实际输出时，按差异修正根因。
- 服务启动、网络中断或超时时，等待后重试；同一题最多重试 3 次。
- 连续失败时保留代码和已填答案，标记阻塞并说明页面错误。
- 不以固定选项序号作答，不伪造通过结果，不盲目重复点击。

## 完成条件

- 以页面自己的通过标记、分数或 `已通过数 / 总关卡数` 核对结果。
- 先核对每组成绩单，再核对课程总览；总览未刷新时重新加载一次，仍不一致则按实际状态汇报。
- 整个指定范围全部通过后，还要确认总览显示“已完成所有练习”或等价状态；仅凭最后一题的成功提示不够。
- 所有指定题组达到满进度后才回复“全部完成”。

遇到登录、验证码、二次验证、敏感数据、付款、权限修改、同名任务或连续 3 次页面错误时停止并交给用户。

## 阶段与工具命令

优先使用当前环境可用的浏览器自动化工具；下面的命令名是能力名称，不绑定某个浏览器产品。

| 阶段 | 常用命令 | 检查点 |
|---|---|---|
| Plan | `listTabs` / `getTab` / `getAXState` / `getScreenshot` | 域名、账号、题型、题目和当前可见编辑器唯一 |
| Do | `getByText` / `getByRole` / `locator` / `click` / `paste` / `pressKey` | 用页面真实存在的“保存”“确认”或“提交代码”操作当前题 |
| Check | `getAXState` / `domSnapshot` / `getScreenshot` / 打开成绩单 | 源码已读回，异步评阅结束，分值和总进度达到完成条件 |
| Act | 根据失败输出、答案视图或测试集修正后重新操作 | 只修根因，同一题最多重试 3 次 |
| Close | `listTabs` / `close` / `markDeliverable` | 保留完成总览，只关闭本次创建的中间页 |

每次输入或点击后立即重新读取状态；如果页面打开新标签页，先用 `listTabs` 重新发现，再按标题和 URL 绑定目标。
