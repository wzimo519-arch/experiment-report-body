# 已验证经验

- Python123 的自由练习没有统一的“交卷”按钮。单项选择题通常用“保存”提交并立即自动判分；编程题逐题“提交代码”并异步返回结果。最终必须看“成绩单”，再看课程总览的 `x / y`。
- Python123 已判分的单项选择题会提供“查看答案”开关。首次得分不完整时，打开该开关读取正确答案和解析，修正后再保存，比反复猜选项可靠。
- Python123 页面同时存在可见题卡按钮和隐藏的全局“交卷”、在线编程控件。按可见题目容器或可访问元素定位，不能直接使用页面中所有按钮的绝对序号。
- Python123 编程题详情页可能保留多个 ACE 编辑器实例，包括隐藏的在线编程抽屉。应选择当前题目详情旁的可见编辑器；从“答案解析”返回后要重新读取状态。
- 编程题的填空模式会显示“点击在此输入一行或多行代码”。必须先点击占位文本，只粘贴缺失代码，再点“确认”。直接把完整源码粘进填空区会导致重复输入语句或覆盖模板约束。
- Python123 评阅可能先显示“服务器正在努力评阅”和逐测试集百分比。这是中间状态，应等待并重新读取状态，不能在此时判定通过或失败。
- 自动判分对输出逐字符比较。实现正确但缺少尾随中文句号、使用不同分隔符或换行，仍可能全部失败；优先复制题目要求中的标点和格式。
- 长题面在可访问树中可能只显示可见部分。必要时读取页面可见正文或截图，确认全部输入输出、边界条件和提示。
- 完成整组后先核对对应成绩单，再返回课程总览确认“已完成所有练习”或等价总进度；最后一题的成功提示不足以证明整组完成。

## Word 与代码环境

- 旧版 `.doc` 报告可能需要使用 Word 自动化而不是 `python-docx`。应原位修改原始文件，并以原扩展名保存。
- 插入正文前要检查准确标题和填写段落。标题后的第一个段落不一定是目标填写位置，应先找到真实占位段或写入点。
- 报告提供表格单元格、形状框、文本框或内容控件时，应先确认这些专用填写位置，内容写入框内或单元格内，不要绕过框另起段落。
- 代码、步骤、过程、运行截图在没有专用填写位置时，优先使用实验正文上方“实验报告文件信息”区域的空白处；不得覆盖已有报告信息，空间不足时再靠近对应正文步骤放置。
- 保持周边字体和间距一致。写入前先读取目标段落的中文字体、字号和行距。
- 占位段若带有图案底纹或字段样式，只修改背景颜色可能无效。应清除段落和字体底纹纹理，或将填写段重建为普通正文，然后重新渲染。
- 每张截图应放在独立段落中。如果图题会与图片分页，应缩小图片或让图题随图片移动。
- 保存原始文档后必须渲染为页面图片并检查所有受影响页面。保存成功不能证明截图、图题或分页正确。
- 截图必须来自实际代码文件和实际运行输出。如果需要可复现结果，应有意识地固定随机种子，并在分析中说明。
- 控制台程序截图前要确认 UTF-8 输出。若平台出现中文乱码，应显式设置运行环境或终端编码。
- 中文 Word 文档常启用行网格（`w:docGrid type="lines"`）。此时内联图片会被压成一行高度、看起来像整片空白，只有图题可见。插入图片前应关闭该节的网格（`PageSetup.LayoutMode = 0`），并给图片段落设置 `DisableLineHeightGrid`；保存后必须渲染确认图片本身可见，而不只是确认 InlineShapes 数量正确。
- 通过 COM 连续插入多张图片时不要依赖 `Selection.TypeParagraph` 换段：它可能静默失败，把多张图塞进同一段落，导致图片互相挤压而不可见。应显式插入段落标记并按段落索引定位（`Range.InsertParagraphAfter` + 索引递增）；整段批量写入也优先用 Range 而不是 Selection。
- PowerShell 5.1 会按本地代码页解析无 BOM 的 `.ps1`，含中文的脚本必须存为 UTF-8 BOM；且通过命令行传中文路径参数不可靠。中文内容多的文档自动化改用 Python + pywin32 更稳定，JSON 内容文件按 UTF-8 读取即可。
- 用户指定的代码目录可能在任务中途被重命名或移动。插入截图前先校验路径存在，失败时先查找名称相近的目录并同步路径，不要直接重建同名目录。
- 本机若未安装「仿宋_GB2312」，`Font.NameFarEast` 赋值会抛 `0x800A16D4` 导致整个格式脚本中断。设置远东字体前应先用已安装字体探测（「仿宋」「宋体」「楷体」可用），或用「仿宋」(FangSong) 代替「仿宋_GB2312」，视觉效果基本一致。
- 用 `Contains` 定位段落时锚点串不要包含 ASCII 空格，中英文混排里的空格常与文档实际字符不一致而导致匹配失败；改用纯中文或无空格片段（如「中新建」「地址引入」）更稳。
- 删除疑似重复内容前，先统计每个锚点出现次数并断言为预期值；计数不符立即中止且不保存，避免误删正文。
- 用户可能同时在 Word 里手动编辑同一文档，此时再做 COM 自动化会拿到同一实例并触发「RPC 服务器不可用 (0x800706BA)」，甚至把内存中的编辑改乱。操作前必须先确认 `WINWORD` 未运行、清理残留 `~$` 锁文件，并请用户先关闭文档。
- 模板自带的浮动文本框可能渲染在末页（同系列空模板末页也有同样的空框）。看到孤立的空边框不要当作垃圾删除，应先对比同系列空模板确认其位置与用途。
